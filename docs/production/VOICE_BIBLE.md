# ZeroSQL «Полынья»: голосовая библия

Кастинг, синтез речи (TTS), словарь ударений, спецификация звука, музыка и эмбиент. Документ для звукорежиссёра, актёров, оператора TTS и композитора.

> **Как пользоваться.** Списки реплик собираются командой **`npm run manifest`** из сценариев `src/data/cases/*/script.json`. Она пишет:
> - `docs/production/voice-lines.csv` — все реплики: `id` (он же имя файла), говорящий, эмоция, текст, ремарка, число знаков, пресет обработки `fx`, пауза в начале `head_ms`, готов ли файл `exists`;
> - `docs/production/voice-by-character.md` — сценарий записи по персонажам с ремарками (для актёров);
> - `docs/production/voice-master.tsv` — план мастеринга для bash-цикла (разд. 6.5);
> - разделы 4.3 и 5.1 этого документа: таблицы генерируются из `tts-voices.example.json` и `pronunciation.json`, руками их не правят.
>
> Дальше: `scripts/tts-batch.example.mjs` (пример пакетной озвучки, разд. 4.8) → прослушка и дубли → мастеринг (разд. 6) → `public/voice/<id>.mp3` → снова `npm run manifest` (столбец `exists`).
>
> Канон: `GAME_DESIGN.md` §2 (речь персонажей), §9.3 (сцена и голос), §11.3 (идентификаторы и правила), §11.4 (эмбиент и музыка); `UI_ART_DIRECTION.md` §9 (звук), §11 (голос и тексты).

## 0. Главное на одной странице

- **12 голосов персонажей + МИРА.** Рассказчик и игрок (Ноль) не озвучиваются: реплики игрока — текст выборов (библия §2.0).
- **Объём:** около 1200 реплик (§11.3): сцены ~750, наводки ~120, «барки» ~150, записи Ирины ~40, МИРА ~80, эпилоги ~60. Реплика — до 160 знаков, 1–2 предложения.
- **Голоса разведены** по трём осям: высота, темп, фактура (разд. 3). Ни один тик не повторяется у двух персонажей.
- **TTS по умолчанию:** ElevenLabs `eleven_multilingual_v2` с голосами из Voice Design. Для самых «актёрских» ролей (Ирина, Гранин, Тоха) — пробы на `eleven_v3`. Кастинг-лист годится и для живых актёров.
- **Файл в игре:** `public/voice/<lineId>.mp3` — MP3 48 кГц, моно, CBR 96 кбит/с. Громкость −16 LUFS (интегральная), пик ≤ −1 dBTP. Тишина: 100 мс в начале (600 мс у реплик-лжи), 250 мс в конце.
- **Мастер:** WAV 48 кГц / 24 бит / моно, обработка (телефон, рация, диктофон…) вшита в файл реплики по столбцу `fx`.
- **Если файла нет**, игра показывает субтитр без звука и больше не запрашивает этот файл до перезагрузки (`media-cache.ts`). Игра полностью проходима без аудио.

## 1. Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Формат в игре | MP3, моно, 48 кГц, CBR 96 кбит/с | Код ждёт `.mp3` (`voiceUrl` в `media-cache.ts`). MP3 играет во всех браузерах, включая Safari. Моно — речь из одной точки. 96 кбит/с совпадает со стандартом SFX (UI §9): около 12 КБ/с, весь сезон (~1200 реплик × ~4,5 с) — около 65 МБ, грузится по реплике. OGG не нужен. |
| Мастер | WAV 48 кГц / 24 бит / моно | Запас под правки и перекодирование. Если TTS отдаёт 44,1 кГц, ресемплинг делается один раз при мастеринге. |
| Громкость | **−16 LUFS** интегральная, ≤ −1,0 dBTP, LRA ≤ 8 LU | Библия §11.3. Исключения по характеру: Бурцев −18 (шёпот не должен «вылезать»), записи Ирины −17. |
| Обработка | Вшивается в файл реплики (`fx`) | Один и тот же персонаж звучит то вживую, то по телефону, а `id` реплики уникален. Обработка в рантайме усложнила бы плеер без выгоды. |
| Пауза лжи | 600 мс тишины в начале файла | Тик лжи Ратникова — полсекундная пауза перед ответом (§2.1). Реплика проигрывается сразу при показе, так пауза звучит естественно. Признак — `lie: true` у реплики или «ложь» в ремарке. |
| Числа | Только словами в тексте для озвучки | §11.3. Скрипт TTS предупреждает о цифрах. |
| Ударения | Словарь `pronunciation.json`, применяется только к тексту для TTS | Субтитры не меняются. |

### 2.14 Кто не озвучивается и голоса вне каста

- `narrator` озвучен **только в открытии и закрытии дел** (сцены `intro`, `outro`, `cold_open`): это голос, который ведёт главы. Титры места и времени и ремарки внутри сцен остаются текстом — иначе сцена превращается в аудиокнигу. Список сцен — `speakers.narrator.voiced_scenes` в `tts-voices.json` и `NARRATOR_VOICED_SCENES` в `scripts/production-manifest.mjs`.
- `player` (Ноль) — без голоса. Скрипт TTS его пропускает.
- Если в сценариях появится говорящий вне каста (ведущий радио, дежурный, медсестра), он берётся из пула «голоса мира»: 2 мужских и 2 женских нейтральных голоса, всегда с обработкой «телефон», «радио» или «за стеклом». Узнаваемым такой голос быть не должен. `npm run manifest` покажет его в `voice-by-character.md` отдельным разделом.

### 4.1 Движок

| Вариант | Когда | Особенности |
|---|---|---|
| **ElevenLabs `eleven_multilingual_v2`** | По умолчанию, все роли | Стабильный тембр, хороший русский. Пауза — SSML-тег `<break time="0.6s" />` (до 3 с). Ударение — акут U+0301 (работает не всегда, проверяйте). Настройки: stability, similarity_boost, style, use_speaker_boost, speed |

### 4.2 Как завести голос

1. **Voice Design** (голос из описания). Возьмите `design_prompt` (английский) из `tts-voices.example.json`. Образец текста для превью должен быть не короче 100 знаков: склейте пробу из разд. 2 с одной-двумя репликами персонажа из `voice-by-character.md`. Сгенерируйте 3–6 превью, выберите, сохраните в библиотеку. `voice_id` впишите в `docs/production/tts-voices.json` (копия примера).
2. **Voice Library** — только голоса с лицензией на коммерческое использование. Условия сохраните.
3. **Клонирование** — только голоса нанятого актёра, с письменного согласия и по договору, где отдельно оговорено синтетическое использование. Голоса реальных людей без согласия не клонируются никогда.
4. Утвердите голос пробой из разд. 2 и тестом разведения (разд. 3), потом фиксируйте настройки.

### 4.4 Как сохранить один и тот же голос между сессиями

- Фиксированы `voice_id`, `model_id`, `voice_settings` и `output_format`, всё в `tts-voices.json` (в git). Голос не перегенерируется: Voice Design — один раз.
- **Seed** детерминированный: хеш `id` реплики плюс номер дубля (`--take`). Повторный прогон даёт тот же дубль, `--take 2` — другой.
- **Контекст:** скрипт передаёт `previous_text` и `next_text` (соседние реплики сцены). Интонация вопроса-ответа не рвётся.
- Пишите сцену целиком за одну сессию, персонажа — пачкой. Журнал `voice-raw/_tts-log.csv` хранит seed и `request-id` каждого файла.
- Меняется версия модели у провайдера — сначала перегенерируйте 10 контрольных реплик (по одной на голос) и сравните со старыми, потом продолжайте.

### 4.5 Ремарки (`direction`) в TTS

Ремарка пишется для актёра, в игре её не видно. В TTS она работает так:

| Ремарка | Что делать в TTS |
|---|---|
| «полушёпот», «шёпот» | v3: тег `[whispers]` (скрипт с `--v3-tags` ставит сам). v2: выбрать дубль тише, speed −0,05 |
| «вздох», «выдох», «дыхание без слов» | v3: `[sighs]` / `[exhales]`. v2: многоточие в начале «…» и выбор дубля |
| «смешок», «хе» | «хе» уже в тексте. v3: `[chuckles]` |
| «медленно», «с паузами» | Тире и многоточия в тексте для TTS; v2 — `<break time="0.5s" />` |
| «книжный регистр (ложь)» | Ровнее и формальнее: stability +0,1 для этой реплики. Пауза 0,5 с добавляется мастерингом (`head_ms` = 600) |
| «на морозе, дыхание сбивается» | Запятые и тире там, где вдох. Пар и мороз — эмбиент, не голос |
| «по телефону», «по рации», «в эфире», «за стеклом», «диктофон», «голосовое» | Ничего: это пресет мастеринга `fx` (разд. 6.4). Синтез делается «сухим» |

### 4.6 Пунктуация и паузы в русском тексте для TTS

- **«—»** — короткая пауза-перелом (около 0,2 с). **«…»** — колебание (около 0,4 с). **Точка** — около 0,4 с, **запятая** — около 0,15 с.
- v2: `<break time="0.6s" />` — не больше 2–3 тегов на реплику, иначе появляются артефакты. В v3 не работает.
- Восклицательный знак TTS читает как крик. Ставить только там, где крик нужен (такого почти нет).
- Вопрос без вопросительного слова («Это он?») интонационно держится на ключевом слове. Если TTS ставит подъём не туда, перестройте фразу так, чтобы ключевое слово было последним.
- Всегда **ё**: «всё», «её», «клюёт».
- Без капса: «МИРА» скрипт заменяет словарём на «Ми́ра», иначе TTS читает по буквам.
- Латиница — только SQL и коды из словаря. Остальное — по-русски.
- **Числа и коды словами:** «восемнадцатое ноября», «двадцать три десять» или «в одиннадцать десять вечера», «ка четыреста четыре тэ о» (номер К404ТО), «бэ-ноль ноль-три», «вэ-эс ноль три». Цифры остаются только в субтитрах (поле `subtitle` в реплике, если тексты расходятся, §11.3).

### 4.7 Ударения

- **Каноническая запись** — комбинируемый акут U+0301 **после** ударной гласной: «Ра́тников». Ё ударна всегда, знак не ставится.
- **Режимы скрипта** (`--stress`):
  - `acute` — как есть (ElevenLabs);
  - `plus` — «+» перед гласной: «Р+атников» (SpeechKit, Silero);
  - `caps` — заглавная ударная гласная: «РАтников» (обходной приём, проверяйте на пробе);
  - `none` — без знаков.
- Словарь применяется только к запросу в TTS. Субтитры не меняются.
- **Орфоэпия служебной речи.** Ловушки для актёров, чаще всего у Ратникова, Мельника и в протоколах: звони́т, догово́р, кварта́л, катало́г, докуме́нт, экспе́рт, обеспе́чение, ходата́йство, осуждённый, возбуждено́ (дело), пригово́р, сре́дства, у́голь — у угля́, при́нял — приняла́. Жаргонное «возбу́ждено» допустимо только в прямой речи персонажа и только по ремарке.

### 4.8 Пакетная озвучка: `scripts/tts-batch.example.mjs`

Это **пример для адаптации**. Сборка и тесты его не запускают, а каждый запуск тратит платные символы.

```bash
npm run manifest                                              # свежий voice-lines.csv
cp docs/production/tts-voices.example.json docs/production/tts-voices.json   # и вписать voice_id
node scripts/tts-batch.example.mjs --dry-run --limit 10       # что уйдёт в TTS (ударения, контекст), без запросов
export ELEVENLABS_API_KEY=…                                   # ключ только из окружения, в файлы не пишется
node scripts/tts-batch.example.mjs --case case-00-nulevoy-etazh          # пролог
node scripts/tts-batch.example.mjs --only burtsev --delay 1200           # один персонаж, реже
node scripts/tts-batch.example.mjs --ids c03.int_burtsev.002 --take 2 --force   # перегенерировать дубль
```

- Пишет сырьё в `voice-raw/<id>.mp3`, или `.wav` при `output_format` вида `pcm_*`. Эту папку не коммитить.
- Пропускает готовые файлы, держит паузу между запросами (`delay_ms`). При 429 и 5xx повторяет с растущим интервалом и учитывает `Retry-After`. На 401/403 останавливается.
- Предупреждает о цифрах и о репликах длиннее 160 знаков.
- Ctrl+C — остановка после текущей реплики.

### 4.9 Прослушка каждого дубля

1. Ударения (особенно имена и SQL), ё, окончания.
2. Нет артефактов: металл, «жевание», обрезанное дыхание, лишние звуки в конце, повтор слова.
3. Эмоция совпадает с полем `emotion` и ремаркой. Тембр совпадает с предыдущими репликами персонажа.
4. Тик персонажа звучит, чужого тика нет.
5. Не больше 3 дублей на реплику. Дальше — правка текста для TTS (не смысла) или запись актёром.

## 6. Аудиоспецификация

### 6.1 Форматы и запись

| Этап | Формат | Где |
|---|---|---|
| Сырьё TTS | MP3 44,1 кГц 192 кбит/с или PCM (`pcm_44100`/`pcm_48000` → WAV) | `voice-raw/<id>.*` (не в git) |
| Запись актёра | WAV 48 кГц / 24 бит / моно. Пики −12…−6 dBFS, шум ≤ −60 dBFS. Сухая комната (RT60 < 0,3 с), конденсаторный микрофон на 15–20 см, поп-фильтр. Для Ирины и Бурцева — ближе (8–10 см): эффект близости | `voice-raw/<id>.wav` |
| Мастер | WAV 48 кГц / 24 бит / моно, обработка и громкость по 6.2–6.4 | `voice-master/<id>.wav` (не в git) |
| **В игру** | **MP3 48 кГц, моно, CBR 96 кбит/с** | **`public/voice/<id>.mp3`** |

**Имя файла = `id` реплики**, формат `<prefix>.<scene>.<nnn>` в нижнем регистре. Выражение: `^(c\d{2}|note|ep|bark|hint|sys)\.[a-z0-9_-]+\.\d{3}$` (§11.3). Пример: `c03.int_burtsev.002.mp3`, `note.n04.001.mp3`, `sys.purge.003.mp3`. Переименовывать файл руками нельзя: меняется `id` в сценарии, потом `npm run manifest`.

### 6.2 Громкость

| Категория | Цель | Пик | Комментарий |
|---|---|---|---|
| Голос (по умолчанию) | **−16 LUFS** | ≤ −1,0 dBTP | Библия §11.3. LRA ≤ 8 LU |
| Бурцев | −18 LUFS | ≤ −1,0 dBTP | Шёпот не должен звучать громче всех |
| Записи Ирины (`dictaphone`) | −17 LUFS | ≤ −1,0 dBTP | Интимность |
| Музыка (мастер петли) | −18 LUFS | ≤ −1,0 dBTP | Под голосом приглушается на −8 дБ (§9.3) |
| Эмбиент-петли `amb.*` | −22 LUFS | ≤ −3 dBTP | В игре множитель 0,35 (UI §9) ≈ −31 LUFS. При голосе −8 дБ за 150 мс, обратно за 600 мс |
| Короткие SFX `ui.*`, `paper.*` | пик −3 dBFS | — | Громкость задают множители категорий в «Параметрах» |

Очень короткие реплики («Не надо.», «Так. Стоп.») меряются ненадёжно. Проверьте их на слух рядом с соседними репликами сцены и подравняйте вручную в пределах ±2 дБ.

### 6.3 Монтаж

- **Голова:** 100 мс тишины до первого звука; у реплик-лжи (`head_ms` = 600) — 600 мс. Вдох перед фразой оставляется, если он часть игры (выдох Ратникова), и входит в эти миллисекунды.
- **Хвост:** 250 мс после затухания последнего звука или выдоха.
- **Фейды:** 5 мс на входе, 20 мс на выходе. Щелчков на стыках нет.
- Убраны клики рта, постоянная составляющая (DC) и резкие «с» (де-эссер −3…−6 дБ на 5–8 кГц).
- Реверберации на «сухих» репликах нет: комнату создаёт эмбиент сцены.

### 6.4 Пресеты обработки (`fx`)

`npm run manifest` ставит `fx` по ремарке: первое совпадение сверху вниз. Записи `note.*` всегда получают `dictaphone`.

| `fx` | Ключевые слова ремарки | Звук | Цепочка ffmpeg (до громкости) |
|---|---|---|---|
| `dry` | — | Чистый голос в комнате | `highpass=f=70` |
| `voice_message` | «голосовое» | Голосовое сообщение мессенджера: узкая полоса, артефакты кодека | `highpass=f=100,lowpass=f=7500,acompressor=threshold=-18dB:ratio=3` + прогон через Opus 16 кбит/с туда и обратно |
| `radio` | «рация» | Рация Даши: узко, перегруз, щелчок шумоподавителя в начале и конце | `highpass=f=400,lowpass=f=2800,acompressor=threshold=-24dB:ratio=6:attack=2:release=60,acrusher=bits=10:mix=0.2` + щелчок `radio_squelch.wav` вручную |
| `phone` | «телефон», «звонок», «в трубке», «на линии», «по связи» | Сотовый звонок | `highpass=f=300,lowpass=f=3400,acompressor=threshold=-20dB:ratio=4:attack=5:release=80,aresample=8000,aresample=48000` |

### 6.5 Мастеринг пачкой

**Рабочий инструмент — `scripts/voice-master.py`** (тот же порядок, что ниже, плюс двухпроходный `loudnorm`; если пик не даёт поднять громкость линейно — усиление и мягкий лимитер на −1,5 dBFS):

```bash
python3 scripts/voice-master.py --raw voice-raw            # весь план из voice-master.tsv
python3 scripts/voice-master.py --raw voice-raw --ids c03.outro.001,c07.confession.003
```

Реплики без слов (текст «…», ремарка «дыхание») TTS не синтезирует — файла у них нет, игра показывает субтитр.

Ручной вариант на bash (справочно):

```bash
# Нужен ffmpeg с libmp3lame (и libopus для voice_message). Сырьё — в voice-raw/, план — в voice-master.tsv.
mkdir -p voice-master public/voice
master_line() {   # id speaker fx head_ms
  local id=$1 speaker=$2 fx=$3 head=$4 raw target=-16 chain
  raw=$(ls voice-raw/"$id".* 2>/dev/null | head -1); [ -z "$raw" ] && return
  [ "$speaker" = burtsev ] && target=-18; [ "$fx" = dictaphone ] && target=-17
  case $fx in
    phone)           chain="highpass=f=300,lowpass=f=3400,acompressor=threshold=-20dB:ratio=4:attack=5:release=80,aresample=8000,aresample=48000" ;;
    radio)           chain="highpass=f=400,lowpass=f=2800,acompressor=threshold=-24dB:ratio=6:attack=2:release=60,acrusher=bits=10:mix=0.2" ;;
    voice_message)   chain="highpass=f=100,lowpass=f=7500,acompressor=threshold=-18dB:ratio=3" ;;
    broadcast_tv)    chain="highpass=f=100,lowpass=f=10000,acompressor=threshold=-18dB:ratio=4:makeup=2,aecho=0.8:0.6:40:0.15" ;;
    broadcast_radio) chain="highpass=f=150,lowpass=f=6000,acompressor=threshold=-18dB:ratio=5:makeup=3,aecho=0.8:0.5:25:0.12" ;;
    glass)           chain="highpass=f=150,lowpass=f=1800,volume=-6dB,aecho=0.8:0.4:15:0.2" ;;
    dictaphone)      chain="highpass=f=120,lowpass=f=7000,acompressor=threshold=-22dB:ratio=3" ;;
    *)               chain="highpass=f=70" ;;
  esac
  ffmpeg -nostdin -v error -y -i "$raw" -ac 1 -ar 48000 -af "$chain,\
silenceremove=start_periods=1:start_threshold=-55dB:start_silence=0.02,areverse,\
silenceremove=start_periods=1:start_threshold=-55dB:start_silence=0.05,areverse,\
afade=t=in:d=0.005,adelay=${head},apad=pad_dur=0.25,loudnorm=I=${target}:TP=-1.0:LRA=8" \
    -c:a pcm_s24le "voice-master/$id.wav"
  ffmpeg -nostdin -v error -y -i "voice-master/$id.wav" -ac 1 -ar 48000 -c:a libmp3lame -b:a 96k "public/voice/$id.mp3"
}
tail -n +2 docs/production/voice-master.tsv | while IFS=$'\t' read -r id speaker fx head; do master_line "$id" "$speaker" "$fx" "$head"; done
npm run manifest   # столбец exists в voice-lines.csv
```

- Цепочки проверены на ffmpeg 6: выход 48 кГц, моно, 96 кбит/с, громкость ≈ −16 LUFS.
- `loudnorm` в один проход работает динамически. Для эталонного качества используйте два прохода: замер `print_format=json`, затем `linear=true` с измеренными значениями.
- `voice_message`: после цепочки прогоните файл через `-c:a libopus -b:a 16k` в `.ogg` и обратно в WAV, потом выставьте громкость.

### 6.6 Как игра ведёт себя без файла

- Реплика показывается сразу. Автовоспроизведение голоса можно выключить. Рядом с текстом — волна, есть повтор реплики и журнал диалога с повтором любой строки (§9.3).
- Пока звучит голос, музыка приглушается на −8 дБ, фон — на −8 дБ за 150 мс и возвращается за 600 мс (§9.3, UI §9).
- Нет файла: первый 404 запоминается, дальше показывается **только субтитр**, повторных запросов до перезагрузки нет (`media-cache.ts`). Игра полностью проходима без звука (§11.3).
- Звук не начинается без действия пользователя (политика браузеров): фон стартует с первым нажатием на холодном открытии (UI §9).

### 6.7 Бюджет TTS (ориентир)

Около 1200 реплик × ~80 знаков ≈ 96 000 знаков. С дублями (+30–50 %) — 125–145 тыс. знаков на весь сезон, плюс пробы голосов. Это укладывается в месячный пакет среднего тарифа ElevenLabs. Стоимость знака зависит от модели и тарифа: проверьте актуальные условия перед запуском.

## 8. Приёмка звука (QA)

1. Имя файла = `id` реплики, путь `public/voice/<id>.mp3`. MP3 48 кГц, моно, CBR 96 кбит/с.
2. Громкость −16 LUFS ±1 (Бурцев −18, записи Ирины −17), пик ≤ −1,0 dBTP. Проверка: `ffmpeg -i f.mp3 -af ebur128=peak=true -f null -`.
3. Голова 100 мс (ложь — 600 мс), хвост 250 мс, без щелчков.
4. Ударения по словарю, ё, числа словами. Нет чужих тиков и чужого тембра.
5. Обработка соответствует `fx`. «Сухие» реплики без реверберации.
6. Тест разведения голосов (разд. 3) пройден для новой партии.
7. Музыка и эмбиент: петли бесшовные (слушать стык 10 раз), громкость по 6.2, под голосом −8 дБ без «качания».

## 9. Права и этика

- **TTS:** коммерческое использование — только на платном тарифе и по условиям провайдера. Сохраните условия на дату генерации.
- **Голоса:** Voice Design — голос аккаунта. Voice Library — по лицензии конкретного голоса. Клонирование — только нанятого актёра, с письменного согласия и отдельной оплатой синтетического использования.
- **Актёры:** договор с отчуждением прав на записи и ремарку о том, будут ли записи использоваться для синтеза. Без явного согласия — не будут.
- **Музыка ИИ:** коммерческая лицензия сервиса, без имён реальных артистов в промптах, квитанции в `audio-src/`.
- **Эмбиент и SFX:** только свои записи, CC0 или библиотеки с лицензией royalty-free. Список источников — в `audio-src/LICENSES.md`.
- **18+:** мат — редко и только у Даши, Шпалы и Тохи (§11.3). Натуралистичных звуков насилия нет.

## 10. Открытые вопросы владельцу

1. **Громкость:** библия задаёт −16 LUFS, а в брифе звучало −18. Оставляю −16 по канону; подтвердить. Для чисто «наушникового» позиционирования можно опустить всё на −18 одной константой.
2. **Живые актёры или TTS** для главных ролей (Ратников, Даша, Нина, Ирина)? Кастинг-лист годится для обоих путей.
3. **Ударения:** подтвердить Шу́стова, Миро́шник, Шпако́в, Ра́тников; SQL как «эс-кью-э́ль» (а не «сиквел»), NULL как «на́лл».
4. **Пути музыки:** утвердить `public/music/<id>.mp3` и стемы `desk_low.l1…l4`; в коде соглашения пока нет.
5. **Категория `foley`** (стук Нины, треск льда) и её множитель громкости в «Параметрах».
6. **Голоса вне каста** (ведущий радиодебатов с Граниным, дежурный): писать ли их, или эти сцены остаются субтитрами с эмбиентом?
7. **Оканье Нины:** TTS передаёт его слабо. Принять компромисс или отдать Нину актрисе?
