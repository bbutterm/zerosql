# Посадки мира «Полыньи»

Посадка — модуль, который кладёт в мир заложенные факты разд. 8.4 библии.
Реестр (`plants/index.ts`) фиксирован: **core → c00 … c12 → eggs**. Посадки идут
до шума; каждая следующая видит резервы и исключения предыдущих.

```ts
// plants/cNN.ts
export function plant(ctx: WorldContext): void { … }
// c09–c12: наполнители поздних таблиц (создаются патчем late.* или импортом диска)
export const late: LateFillers = { bank_statements(db, rng, { flags, clock }) { … } };
```

## Контракт посадки

| Что нужно | Как |
|---|---|
| Строка с id из библии | `ctx.insert(table, { id, … })` — id резервируется, шум его обходит |
| Строка, чей id зависит от порядка (incidents, audit_log, query_log, statements 2026, incident_persons, migration_jobs, attachments) | `ctx.insert(table, row, { orderAt })`: с явным id — это **якорь** (шум встанет до и после него ровно по порядку ключа), без id — **плавающая** строка (получит id по своему моменту) |
| «Живые» таблицы ЗЕРКАЛА (plate_reads, door_access, purchases, transactions, messenger_events, intercom_events, gs_comms_2015, morgue_records…) | `ctx.insert(table, row, { orderAt: parseTs(ts) })` без id — id выдаются по времени вперемешку с шумом |
| Дыра в id (удалённая строка) | `ctx.hole(table, id, orderAtMs)` |
| Дыра в журнале «Сокола» | `ctx.reserve("doc_reg_hole", "4471", parseTs("2015-03-10 14:00:00"))` |
| Номер КУСП, который шум не должен выдать | `ctx.reserve("kusp:2026", "4921")` |
| Уникальный ключ (номер машины, телефон, логин, пропуск, счёт, ИНН, act_no, case_id, адрес `улица\|дом\|кв`) | `ctx.reserve(kind, value[, ref])` — виды: `plate`, `phone`, `login`, `badge`, `account`, `inn`, `act_no`, `case_id`, `address`, `card_no`, `contract_no`, `deal_no`, `company_name`, `workstation`, `gs_ext` |
| «Ровно N строк», «только он был у камеры» | `ctx.exclude(table, (row) => …)` — шум перестраивает строку до 20 раз, иначе генератор падает |
| Объём таблицы | шум добирает до цели разд. 8.2 сам: `цель − посажено` |

Время — `'YYYY-MM-DD HH:MM:SS'` (местное), даты — `'YYYY-MM-DD'`. Константы — в `../facts.ts`
(там же числовые якоря: `GEO`, `DOC_REG`, `GHOST_SESSIONS`, `CRON_JOBS`, `MIGRATION_FINAL`…).
Проверка: `src/__tests__/world/*.test.ts`; тест дела добавляет свои факты в `src/__tests__/cases/cNN.test.ts`.
