# Посадки мира «Полыньи»

Посадка — модуль, который кладёт в мир заложенные факты разд. 8.4 библии.
Реестр (`plants/index.ts`) фиксирован: **core → c00 … c12 → eggs**. Посадки идут
до шума; каждая следующая видит резервы и исключения предыдущих.

```ts
// plants/cNN.ts
export function plant(ctx: WorldContext): void { … }
// c09–c12: наполнители поздних таблиц (создаются патчем late.* или импортом диска)
export const late: LateFillers = { bank_statements(db, rng, { flags, clock }) { … } };
```

## Контракт посадки

| Что нужно | Как |
|---|---|
| Строка с id из библии | `ctx.insert(table, { id, … })` — id резервируется, шум его обходит |
| Строка, чей id зависит от порядка (incidents, audit_log, query_log, statements 2026, incident_persons, migration_jobs, attachments) | `ctx.insert(table, row, { orderAt })`: с явным id — это **якорь** (шум встанет до и после него ровно по порядку ключа), без id — **плавающая** строка (получит id по своему моменту) |
| «Живые» таблицы ЗЕРКАЛА (plate_reads, door_access, purchases, transactions, messenger_events, intercom_events, gs_comms_2015, morgue_records…), а также registrations и employment | `ctx.insert(table, row, { orderAt: parseTs(ts) })` без id — id выдаются по времени (`from_date`) вперемешку с шумом |
| Строка без id и без `orderAt` в таблице с целым `id` | id выдаёт аллокатор (`ctx.nextId`) сразу при вставке — шум его обойдёт. Не полагайтесь на `max(rowid) + 1` |
| Шумовой житель под посадку (директор, инженер, свидетель — человек с id из библии, которого нет в верхней таблице) | `ctx.reserve("person:adult", String(id), { bornFrom, bornTo })` — шум положит на id живого взрослого нужных лет, не дубль карточки (`AdultReservation` в `../facts.ts`) |
| Дыра в id (удалённая строка) | `ctx.hole(table, id, orderAtMs)` |
| Дыра в журнале «Сокола» | `ctx.reserve("doc_reg_hole", "4471", parseTs("2015-03-10 14:00:00"))` |
| Номер КУСП, который шум не должен выдать | `ctx.reserve("kusp:2026", "4921")` |
| Уникальный ключ (номер машины, телефон, логин, пропуск, счёт, ИНН, act_no, case_id, адрес `улица\|дом\|кв`) | `ctx.reserve(kind, value[, ref])` — виды: `plate`, `phone`, `login`, `badge`, `account`, `inn`, `act_no`, `case_id`, `address`, `card_no`, `contract_no`, `deal_no`, `company_name`, `workstation`, `gs_ext` |
| «Ровно N строк», «только он был у камеры» | `ctx.exclude(table, (row) => …)` — шум перестраивает строку до 20 раз, иначе генератор падает |
| Объём таблицы | шум добирает до цели разд. 8.2 сам: `цель − посажено` |

Время — `'YYYY-MM-DD HH:MM:SS'` (местное), даты — `'YYYY-MM-DD'`. Константы — в `../facts.ts`
(там же числовые якоря: `GEO`, `DOC_REG`, `GHOST_SESSIONS`, `CRON_JOBS`, `MIGRATION_FINAL`…).
Проверка: `src/__tests__/world/*.test.ts`; тест дела добавляет свои факты в `src/__tests__/cases/cNN.test.ts`.

## Известные расхождения с библией (не закрыты)

- **Висяк side-06 «Мёртвые души» (разд. 10.3)** ждёт, что без прописки, телефона и работы — ровно 7 человек
  (Кравец и ещё шестеро). При объёмах разд. 8.2 (persons 4 301, registrations 2 200, phones 1 800,
  employment 1 800) таких в шуме сотни: дети, умершие, дубли карточек и взрослые без записей. Условие
  висяка нужно уточнить в библии (например, `created_at` после даты или отсутствие ещё и в `incident_persons`),
  либо перераспределить шум прописок/телефонов. Кравец единственный по сочетанию «нет прописки, телефона и
  работы» + `created_at` после смерти Ирины (карточки шума заведены до вечера 18.11; карточку игрока 9000
  вставляет патч `p0.player` 02.12, и прописки у неё тоже нет — см. ниже).
- **Прописка игрока.** Запрос «сторожа» в Д9 (`… registrations r … WHERE r.person_id = 9000; -- Не надо.`)
  ищет адрес игрока, а «Бастион» стоит у общежития на ул. Строителей (камера 31). Строки `registrations`
  для 9000 библия не называет, поэтому `p0.player` её не вставляет и запрос сторожа возвращает 0 строк.
  Если адрес игрока нужен (общежитие, ул. Строителей), его надо добавить в патч `p0.player` и в разд. 8.4.
